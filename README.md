# Grammar Tracker

Локальное веб-приложение для изучения английской грамматики: план по уровням, повторения с интервалами, упражнения по одному вопросу, статистика и журнал ошибок.

## Возможности

- Анкета при первом запуске: уровень A1–C1, минут в день, дни недели, цель.
- План из 14 тем; доступные темы фильтруются по выбранному уровню. Для A1 — первые 10 тем.
- Занятие: повторение + новая тема, по 5 упражнений на тему, краткое правило и фраза вслух.
- При ошибке приложение объясняет, что не так, и показывает правильный ответ.
- Повторения по схеме: 1 → 3 → 7 → 14 → 30 дней. Если точность по теме ниже 80%, интервал сбрасывается.
- Статистика: серия дней, точность, прогресс по плану, отчёт за 7 дней, журнал ошибок.
- Данные хранятся в `localStorage` браузера. Внешних сервисов и runtime-зависимостей нет.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm start
```

Откройте http://localhost:3000.

Другой порт:

```bash
PORT=4000 npm start
```

В PowerShell:

```powershell
$env:PORT = 4000
npm start
```

## Скрипты

- `npm start` — поднять локальный статический сервер.
- `npm run check` — проверить синтаксис `app.js` и `server.js`.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Каркас интерфейса |
| `styles.css` | Стили и адаптивная вёрстка |
| `app.js` | Профиль, план, тренажёр, повторения, статистика и отчёты |
| `server.js` | Статический сервер на встроенном модуле `http` |
| `package.json` | Скрипты запуска и проверки |

В `app.js` темы лежат в массиве `TOPICS`, объяснения ошибок — в `MISTAKE_WHY`.

## Как пользоваться

1. Заполнить анкету: уровень, время, дни и цель.
2. Нажать «Начать занятие» и отвечать по одному вопросу за раз.
3. После ошибки прочитать объяснение и правильный ответ, затем нажать «Далее».
4. Следить за прогрессом в разделах «План», «Статус», «Отчёт» и «Ошибки».
5. Кнопка «Сброс» удаляет профиль и весь прогресс.

## Как добавить тему

Добавьте объект в `TOPICS`:

```js
{
  id: 'new-topic',
  level: 'A2',
  title: 'Новая тема',
  rules: ['Правило 1', 'Правило 2'],
  oral: 'Пример фразы вслух.',
  exercises: [
    { prompt: 'I ___ here.', answer: 'am' }
  ]
}
```

Для пояснения ошибок добавьте записи в `MISTAKE_WHY` по ключу `id:индекс_упражнения`, например `'new-topic:0'`. Если записи нет, используется первое правило темы.
